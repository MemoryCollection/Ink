# 墨 Ink

一个安静一点的 Typecho 主题。单栏、居中、纸面质感，适合以阅读为主的个人博客。

要求：**Typecho 1.2 及以上**（在 1.3.0 上验证）。

## 特性

- **一页纸**：整站收在 840px 宽的一张纸上，标题、正文、页脚同宽，四周留白
- **7 套配色 + 三态明暗**：石墨蓝（默认）/ 玫瑰紫 / 珊瑚橙 / 孔雀青 / 深海蓝 / 靛蓝紫 / 罗兰紫，配色与明暗合并在导航右侧一枚按钮里；明暗分「自动 / 浅色 / 深色」，默认自动（跟随系统），配色写 cookie、明暗写 localStorage，首屏不闪色
- **首页即目录**：按时间倒序平铺全部文章，日期成列，篇数与最近更新在标题区
- **文章页**：无目录，正文独立居中；代码块带语言标签、行号、一键复制；图片点击灯箱；顶部阅读进度线
- **配色跟随的矢量标识**：站名左侧的圆章是内联 SVG，描边用 `var(--accent)`，切换配色与暗色时自动变；favicon 也按当前配色现画
- **导航自定义图标**：最多 5 个，基于草莓图标库（Strawberry Icon Free），后台填名字和链接即可
- 评论全站关闭，无社交组件、无多余脚本

## 安装

1. 把 `ink` 整个目录放进 `usr/themes/`，或在后台「控制台 → 外观 → 添加主题」上传 zip
2. 后台启用「墨 Ink」
3. 到「外观 → 设置外观」填首页大标题、默认配色、页脚文字、备案号、图标等

## 主题设置

「外观 → 设置外观」里按六组折叠，改完点页面底部保存即可，不用碰代码：

| 分组 | 项 | 说明 |
| --- | --- | --- |
| 首页 | 首页大标题 / 站点描述 | 标题用 `<em>` 包住的字会变成渐变强调色 |
| 外观 · 配色 | 默认配色 / 强调色来源 / 自定义强调色 | 默认石墨蓝；也可选「跟随访客」记住访客上次选的；强调色可填一个品牌色覆盖全部强调 |
| 外观 · 版式 | 首页标题对齐 / 导航平铺分类 | 标题左对齐 / 靠右 / 靠右 + 分隔线收短。**只影响首页标题区，归档列表任何档位都保持左对齐** |
| 字体 | 字体风格 / 自定义标题字体 / 自定义正文字体 | 预设：标题衬线+正文黑体 / 全黑体 / 全衬线 / 标题等宽 |
| 字号与版面 | 正文字号 / 行高 / 纸宽 / 纸内边距 | 只填数字；只改「正文字号」一行，全站字号按比例联动（详见下节） |
| 页脚 | 页脚文字 / 备案号 | 备案号自动链到工信部备案系统 |
| 导航图标 | 图标 1–5 的名字 / 链接 / 文字 / 新窗口 | 链接留空即不渲染 |

想核对这些字段长什么样，可以打开仓库根的 `admin-preview.html`（后台设置页的静态预览，不参与运行）。
这份预览不是手绘的：它由真实的 Typecho 1.3 表单类渲染 `themeConfig()` 的控件、再跑一遍排版脚本生成。

### 自定义设置页是怎么接上去的

Typecho 的 `Form::render()` 有个特性：一旦 `$form->html(...)` 被赋过值，它就只输出这段 HTML，
`addInput()` 进来的子元素全部不再输出。所以主题这样接：

1. `themeConfig()` 照常 `addInput()` 建全部字段（**保存逻辑完全依赖它，不要动**）；
2. `themeConfigHtml()` 生成整页自定义排版，每行留一个 `.ink-input` 落点，末尾写回 `$form->html()`；
3. 写入之后手动把每个元素 `render()` 进 `#ink-cfg-forms` 隐藏容器 —— 真正的 `<input name="…">` 只在这一步才存在；
4. 一小段 JS 按 `data-field` 把原生控件搬进对应行，搬完给容器加 `.is-busy` 收起。

脚本没跑或抛错时，`#ink-cfg-forms` 保持展开、字段照样可改，不会出现"设置项消失"。

## 换字体 / 换字号

两种办法：后台「字体」「字号与版面」两组直接填；或者改 `style.css` 顶部的几行变量，其余样式自动跟随（后台没填的项才用这里的值）：

```css
/* 字体 */
--serif: "Noto Serif SC", ..., "SimSun", Georgia, serif;   /* 标题、站名、列表标题、正文小标题 */
--sans:  -apple-system, ..., "Microsoft YaHei", sans-serif; /* 正文、导航、页脚 */
--mono:  ui-monospace, "SF Mono", ..., monospace;           /* 日期、代码 */

/* 字号：只改这两行 */
--fs-body:  17px;    /* 正文 —— 全站字号都由它派生 */
--lh-body:  1.9;     /* 正文行高 —— 段距、块距都由它派生 */

/* 版面 */
--sheet-w:  840px;   /* 纸宽 */
--sheet-pad: 56px;   /* 纸内边距 */
--gap:      32px;    /* 纸到窗口边缘 */
```

### 字号是全站联动的

`--fs-title`、`--fs-h1`、`--fs-list`、`--fs-meta`、`--fs-label` 以及正文里各级标题、
引用、表格、代码块，全部写成 `calc(var(--fs-body) * 倍数)`，段距块距写成
`calc(var(--fs-body) * var(--lh-body) * 倍数)`。所以：

- 把 `--fs-body` 从 17px 调到 20px，**首页大标题、列表标题、文章标题、正文、代码块一起放大 1.18 倍**，
  比例不变，不会出现「正文变大了、列表标题还是老的」；
- 把 `--lh-body` 调到 2.2，段距、块距会跟着变松（它们是按「一个行距」算的）；
- 手机端三档断点（900 / 640 / 520px）只在倍数上收一点，**不再另写固定像素**。

想直观对比三档字号，打开仓库根的 `font-scale.html`（同一段内容按 17 / 20 / 15px 并排）。

> 后台注入的变量在 `header.php` 里位于 `style.css` **之后**。这是必须的：
> 两处都写 `:root { --fs-body: … }` 时优先级相同，后出现的赢。反过来的话，
> 后台改的字号、行高、纸宽会被 `style.css` 里的默认值盖掉。

改完记得让浏览器重新拉一次样式（主题用文件修改时间做 ?v= 指纹，正常会自己更新）。

## 配色

七套，靠 `<html data-palette="…">` 切换；不写这个属性就是石墨蓝。

| 名称 | 键 | 主色 | 渐变终点 | 深色主色 |
| --- | --- | --- | --- | --- |
| 石墨蓝（默认） | `graphite` | `#4b5c6c` | `#5e86a1` | `#6d8fb0` |
| 玫瑰紫 | `rose` | `#9c3a5e` | `#cb526e` | #d6668f |
| 珊瑚橙 | `coral` | `#cf5b30` | `#e39b63` | #eb987a |
| 孔雀青 | `peacock` | `#21757d` | `#27bebc` | #2bcbda |
| 深海蓝 | `abyss` | `#23487b` | `#297fbc` | #2d74d7 |
| 靛蓝紫 | `indigo` | `#49418b` | `#7f56bd` | #7268ca |
| 罗兰紫 | `violet` | `#7d4c9a` | `#b46bc2` | #b17dcf |

每套都同时给了浅色与深色两份变量（深色用 `[data-theme="dark"][data-palette="x"]` 精确命中），
纸面、桌面、三级墨色、细线、代码底色、语法着色全部随配色走，不是只换一个强调色。
正文与次要文字的对比度都在 15:1 / 7:1 以上，深色下同样。

- 前台切换：导航右侧的双色圆点，选完写入 cookie `ink_palette`
- 明暗三态：面板下半是「自动 / 浅色 / 深色」，**默认自动**，跟随系统的
  `prefers-color-scheme`；手动选过浅色或深色后就不再被系统覆盖。
  存的是选择（`data-mode`），实际生效的写在 `data-theme` 上，所以 CSS 只需一套
  `[data-theme="dark"]`，不用为「自动」再复制一遍配色变量
- 后台设默认：外观 → 设置外观 → 「默认配色」
- 加一套：在 `ink_palettes()` 里加一行，再照着 `style.css` 里任意一个
  `[data-palette="…"]` 块复制一份改色值即可；JS 的配色列表是读按钮的，不用改
- 旧 cookie：改名后访客浏览器里残留的旧键（如 `celadon`）会自动回退到默认配色，不会白屏

配色总览见仓库根的 `palettes.html`（七套 × 明暗 14 张卡片并排）。

## 图标

后台「设置外观 → 导航图标」共 5 组：图标名、链接、悬停文字、是否新窗口。
链接留空即不渲染；图标名留空时按网址自动猜一个（github / rss / mailto 等）。

图标名取自`assets/css/icons.css` 里的 `czs-*` 类名，完整 380 枚可在仓库根的 `icons.html` 里搜索、点击复制。
