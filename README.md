# 墨 Ink

一个安静一点的 Typecho 主题。单栏、居中、纸面质感，适合以阅读为主的个人博客。

要求：**Typecho 1.2 及以上**（在 1.3.0 上验证）。

## 特性

- **一页纸**：整站收在 840px 宽的一张纸上，标题、正文、页脚同宽，四周留白
- **6 套配色 + 明暗模式**：青瓷 / 朱砂 / 松烟 / 靛蓝 / 绛紫 / 赭石，配色与明暗合并在导航右侧一枚按钮里；配色写 cookie，明暗写 localStorage，首屏不闪色
- **首页即目录**：按时间倒序平铺全部文章，日期成列，篇数与最近更新在标题区
- **文章页**：无目录，正文独立居中；代码块带语言标签、行号、一键复制；图片点击灯箱；顶部阅读进度线
- **配色跟随的矢量标识**：站名左侧的圆章是内联 SVG，描边用 `var(--accent)`，切换配色与暗色时自动变；favicon 也按当前配色现画
- **导航自定义图标**：最多 5 个，基于草莓图标库（Strawberry Icon Free），后台填名字和链接即可
- 评论全站关闭，无社交组件、无多余脚本

## 安装

1. 把 `ink` 整个目录放进 `usr/themes/`，或在后台「控制台 → 外观 → 添加主题」上传 zip
2. 后台启用「墨 Ink」
3. 到「外观 → 设置外观」填首页大标题、默认配色、页脚文字、备案号、图标等

## 换字体 / 换字号

只改 `style.css` 顶部的几行变量，其余样式自动跟随：

```css
/* 字体 */
--serif: "Noto Serif SC", ..., "SimSun", Georgia, serif;   /* 标题、站名 */
--sans:  -apple-system, ..., "Microsoft YaHei", sans-serif; /* 正文 */
--mono:  ui-monospace, "SF Mono", ..., monospace;           /* 日期、代码 */

/* 字号 */
--fs-body:  17px;                          /* 正文 */
--lh-body:  1.9;                           /* 正文行高 */
--fs-title: 1.55rem;                       /* 首页 / 分类页标题 */
--fs-h1:    clamp(1.6rem, 2.4vw, 2rem);    /* 文章标题 */
--fs-list:  16px;                          /* 列表标题 */

/* 版面 */
--sheet-w:  840px;   /* 纸宽 */
--sheet-pad: 56px;   /* 纸内边距 */
--gap:      32px;    /* 纸到窗口边缘 */
```

改完记得让浏览器重新拉一次样式（主题用文件修改时间做 ?v= 指纹，正常会自己更新）。

## 图标

后台「设置外观 → 图标 N」共 5 组：图标名、链接、悬停文字、是否新窗口。
链接留空即不渲染；图标名留空时按网址自动猜一个（github / rss / mailto 等）。

图标名取自`assets/css/icons.css` 里的 `czs-*` 类名，完整 380 枚可在仓库根的 `icons.html` 里搜索、点击复制。
